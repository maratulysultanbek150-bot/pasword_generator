#  Генератор паролей

Консольный скрипт на Python для безопасной генерации случайных паролей.

##  Функционал
- Настройка длины пароля и выбора набора символов (буквы, цифры, спецсимволы).
- Использование криптографически безопасного модуля `secrets`.
- Обработка некорректного ввода пользователя (защита от вылета).

##  Требования
- Python 3.8 или выше

##  Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/maratulysultanbek150-bot/password_generator.git
```

2. Перейдите в директорию проекта:
```bash
cd password_generator
```

3. Запустите скрипт:
```bash
python main.py
```

