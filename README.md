# Password Generator

Консольный скрипт на Python для генерации случайных паролей.

## Функционал
- Настройка длины пароля и набора символов (буквы, цифры, спецсимволы).
- Использование модуля `secrets` для генерации.
- Обработка некорректного ввода пользователя.

## Использование
Запуск из терминала:
```bash
python main.py
